# Suger Rush: Custom Sugarcane
![alt text](image.png)

### A Fun game I made in pygame
#### The idea is simple, you got 30 seconds to harvest as many sugarcane as possible. There is Also Golden Sugarcane which gives you more sugar. Once you get a combo, you get a sugar rush which gives you Speed and haste to harvest even more sugarcane! 
I had one challnge, Finish the whole game in one file!

## Run the game:
```
git clone https://github.com/timodev96-alt/Custom-Sugarcane.git
cd Custom-Sugarcane
pip install -r requirements.txt
python app.py
```
